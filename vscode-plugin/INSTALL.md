# Quick Installation Guide

This directory contains the VSCode/Cursor IDE extension for Proto-Vulcan syntax highlighting.

## 🚀 Quick Install

### For VSCode

**Linux/macOS:**
```bash
./install.sh
```

**Windows:**
```bash
install.bat
```

### For Cursor IDE

**Linux/macOS:**
```bash
./install-cursor.sh
```

**Windows:**
```bash
install-cursor.bat
```

## 📋 What Gets Installed

The extension provides:
- Syntax highlighting for `.pv` files
- Auto-closing brackets and quotes
- Comment toggling (Ctrl+/)
- Code folding support
- Proper indentation

## 🧪 Test Installation

After installation:
1. Restart your editor
2. Open any `.pv` file from the `../tests/` directory
3. You should see syntax highlighting applied automatically
